# 公网访问：把网盘暴露到你家之外

> 面向主人自己的操作手册。以**樱花 FRP** 为主，末尾附其它穿透工具的差异点。
> 托盘面板「公网访问 → 怎么配置？」里是同一份流程的精简版。

---

## 0. 先搞清楚一件事：填地址≠能用

很多人第一反应是「穿透工具给了个地址，粘进面板就行」。**不行。**

本机的 HTTPS 证书是 Caddy 用内部 CA 签的，**只对配置里写明的名字有效**：

```
localhost / 127.0.0.1 / 本机局域网 IP
```

穿透工具给你的 `cn-bj.frp.one` 不在这个名单里。客户端拿它去连，会在
**TLS 握手阶段被直接掐断**（实测报错 `SEC_E_INTERNAL_ERROR`，HTTP 状态码
`000`）—— 连 HTTP 层的错误页都出不来。

所以链路是三步，顺序不能反：

```
① 穿透工具建隧道（把公网流量送到本机 8765）
② 本机认这个域名（写进 Caddy 配置 + 重签证书）   ← 面板的「一键接入」干这个
③ 面板里填完整公网地址（一键接入成功后自动填好）
```

---

## 1. 穿透侧：建一条 TCP 隧道

以樱花 FRP 为例：

1. 打开 <https://www.natfrp.com>，注册并登录
2. 下载客户端（Windows 版），用账号的**访问密钥**登录
3. 「隧道」→ 新建隧道：

   | 字段 | 填什么 | 说明 |
   |---|---|---|
   | 隧道类型 | **TCP** | 不要选 HTTP；本机是 HTTPS，HTTP 隧道会二次反代出问题 |
   | 本地地址 | `127.0.0.1` | 必须回环，不是 `0.0.0.0` |
   | 本地端口 | `8765` | 本机 Web 端口（安装时可能改过，以面板显示为准） |
   | 远程端口 | 挑一个没被占的，如 `35123` | 免费用户通常要在它给的区间里选 |
   | 绑定域名 | 默认给它给的节点域名 | 一般不用改 |

4. 启动隧道，确认状态是「在线」
5. 记下完整地址：**节点域名 + 远程端口**

   ```
   cn-bj.frp.one:35123
   ```

> 樱花有多个节点，域名各不相同（`cn-bj.frp.one` / `cn-hk.frp.one` …）。
> 换节点 = 换域名 = 要重新接入一次（见第 3 节）。

---

## 2. 本机侧：让 Caddy 认这个域名

### 推荐：面板一键接入

托盘面板 →「公网访问」→ 把 `cn-bj.frp.one:35123` 粘进**隧道域名**输入框 →
点 **「一键接入」**。

程序会依次做：

1. 解析出域名 `cn-bj.frp.one`
2. 把它追加进 `conf\Caddyfile` 的站点地址行（保留原有的 localhost / 局域网 IP）
3. 备份原配置到 `Caddyfile.wanbak`
4. 重启 Caddy 服务 → 内部 CA 为新域名签证书
5. 用「SNI=域名、目标=本机 8765」的方式自检 `/healthz`
6. 通过后把 `https://cn-bj.frp.one:35123` **自动填进公网地址并保存**

失败时会把失败的那一步和原因直接显示出来（比如 TLS 握手失败 = 域名没被认）。

### 手工方式（不推荐，仅备用）

改 `conf\Caddyfile` 的站点地址行，把域名加进去（**保留 `:8765`**）：

```caddyfile
https://localhost:8765, https://127.0.0.1:8765, https://192.168.1.100:8765, https://cn-bj.frp.one:8765 {
	tls internal
	...
}
```

然后重启服务：

```powershell
Restart-Service lanshare-caddy
```

⚠ 这个文件头部写着「不要手改」——重装/升级会重新生成，手改内容会丢。
一键接入是同一套逻辑，但会保留原有主机名，且能被重复执行。

## 3. 验证

1. **手机切到移动流量**（关键：不要连家里 WiFi，否则走的是局域网路径，
   验不出公网）
2. 打开 `https://cn-bj.frp.one:35123`
3. 浏览器提示「证书不受信任」→ 点「继续访问」（自签证书，正常现象）
4. 看到网盘登录页 = 通了

手机 App 里：服务器地址填同一个 URL，首次连接会弹「信任此服务器」（显示
SHA256 指纹），点信任即可，之后不再问。

## 4. 排错表

| 现象 | 原因 | 怎么办 |
|---|---|---|
| 浏览器「无法连接」/ 超时 | 隧道没在线，或本地端口填错 | 回樱花客户端看隧道状态 |
| `ERR_SSL_PROTOCOL_ERROR` / 握手失败 | **域名没接入本机**（最常见） | 先点「一键接入」 |
| 打开是 404 | 域名进了 Caddyfile 但站点块没匹配 | 检查站点地址行有没有该域名 |
| 能打开但提示证书错误 | 自签证书，正常 | 点继续；App 里点信任 |
| 局域网能开，外网不行 | 隧道不通 | 看樱花客户端日志 |
| 之前能用，换节点后不行 | 域名变了 | 用新地址重新「一键接入」 |

## 5. 其它穿透工具

流程完全一样，只是第 1 步的界面不同。要点：

- **必须用 TCP 隧道**，本地目标 `127.0.0.1:8765`
- 拿到「域名:端口」后，一样粘进「隧道地址」点一键接入
- frp 自建：`[web] type=tcp, local_ip=127.0.0.1, local_port=8765, remote_port=xxxx`，
  域名取 `subdomain.你的域名` 或直接用服务器 IP（IP 也能接，同样的道理）

> 用 frp 自建且**域名走你自己的公网 CA**（不是 Caddy 内部 CA）时，可以跳过
> 一键接入直接填地址 —— 那种情况下证书本来就是公网可信的。但只要证书是
> 本机 Caddy 签的，就必须先接入。

---

## 6. 两个长期注意事项

**IP 会变**：`Caddyfile` 里的局域网 IP 是安装/开启局域网时写进去的。路由器
换了网段（比如 `192.168.1.x` → `192.168.0.x`），局域网那份配置就失效了 ——
重新点一次「开启局域网服务」即可。公网域名不受影响。

**证书到期**：本机根 CA 有效期 10 年（到 2036）。到期那天所有设备会同时报
证书错误，面板会提前一年提示。
