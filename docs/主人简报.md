### 修的东西里最有分量的四件

1. **配额「覆盖上传」家族缺陷（5 处写路径，2 处带破坏性失败路径）**
   原实现「旧版先进回收站 → 再验配额」：配额拒时旧文件已经离开原位，
   等于**失败的替换真的把文件换掉了**。另三处把旧版双计，导致配额内正常的
   覆盖上传被误拒。现在四条写路径（直传/分片/秒传/WebDAV）统一按**净增量**
   计价，预检先于一切写动作。预发栈真实服务器 E2E：DAV 覆盖超配额 409 且
   旧文件原样（修前此处文件已进回收站）。
2. **成员改名联动缺口** —— 改名迁了专辑/私人目录，分享与回收站行还指旧路径：
   改名后私人分享下载 404、回收站恢复进已消失的旧目录，**看起来像数据丢了**。
3. **笔记搜索 474ms → 18ms（26x）** —— 0 命中查询每次付一次全树 rglob
   （5000 文件树实测），11-08 perf 批的短路优化没覆盖到它。
4. **安全面四处**：`.lanshare-pgpass` 用 `os.chmod` 收紧 ACL（**在 Windows
   根本不生效**，P1 暴露面一直裸着）、带口令连接串撤离服务注册表、WebView2
   导航护栏（非本应用源一律取消）、托盘 UI innerHTML 转义补齐。

另有：通知广播并发双发 CAS 化 + 投递崩溃补偿、同名分享取件记录串线、
清单重命名重名不变量、他人 private 分类名泄漏、备份脚本三缺陷
（v3.70 起从未真跑过，首跑即实证）。

## 发布前独立复核（2026-11-09 上午）

夜批改完、发版前又做了一轮独立复核，抓到 6 处「改了但没改到位」，全部修掉：

1. **明文口令还留在注册表** —— 夜批把连接串从服务环境变量撤到 `.lanshare-dburl`，
   但 `HKLM\SOFTWARE\LANShare\PgPassword` 还写着同一个口令，而那个键的
   ACL 是 `BUILTIN\Users: ReadKey`，本机任意账号照样读得到。现在 CLI 只写
   数据目录 `.lanshare-pgpass`，并主动删注册表里的历史值；读取改文件优先。
2. **存量口令文件的 ACL 没被收紧** —— `os.chmod` 不生效那条只对新写入生效，
   生产上那个文件实测还是 `Users:(M)` + `Authenticated Users:(M)`。
   **已就地收紧**到 SYSTEM / Administrators（服务以 LocalSystem 跑，不受影响）。
3. **连接串文件读不到会静默退 SQLite** —— 那会让 API 带一个空库起来，
   用户看到「文件全没了」。改成 fail-fast，宁可服务起不来。
4. **外部备份对账结果不影响退出码** —— `match=False` 打印一句「属预期」
   然后照样 exit 0，真丢了文件也没人知道。改成目标侧少于源侧即非 0。
5. **perf 基线的零命中读数采了没落盘** —— `se0` 跑了却不进输出，
   「教训制度化」当时只落在注释里。已补进输出。
6. **托盘 `ArgQuoting` 的文档注释错位** —— 它插进了 `InstallerBusy` 的
   `<summary>` 里，导致 `InstallerBusy` 的成因说明挂到了错误的类上。

## 回来后你要做的

**插上外置盘跑首次真实备份**（这是新功能解冻的钥匙）：

```
python scripts/backup_files_external.py --dest <外盘>:\lan-share-files --dry-run
```

先看预计规模，去掉 `--dry-run` 正式跑。manifest / log 都落目标盘根，
双侧对账 `match=true` 即成。生产规模只读 dry-run 实测 8688 文件 / 20.35 GB
/ 1.9s（正式跑 I/O 压力未实测，预计 20-40 分钟，夜间低峰为宜）。

## 等你拍板

1. **PG 门禁那个「8 红」**：同一 HEAD 重跑就全绿，四次对照实验无一稳定复现，
   定性为间歇性时序依赖（首要嫌疑：进程内限速桶滑窗）。要不要在 dev_stack
   复跑确认？不确认就一直是「不知道有没有真问题」。
2. **PG 日志黑洞**（老账）：`logging_collector=off` + 无 stdout 重定向，
   数据库侧出事的线索全丢。开 collector 还是改 NSSM 托管？
3. **自检报警邮件**（老账）：`HermesSelfCheck` 以 SYSTEM 身份跑，HOME 落到
   systemprofile 目录没有 `.env`，已连续 9 天发不出报警。
   A) 在那个目录放只含 `QQMAIL_*` 的 `.env`；B) 任务改以 Administrator 运行。
4. **`lanshare_cli` 里十几处无效转义**（`HKLM\SOFTWARE\` 之类单反斜杠）：
   Python 3.11 只是 DeprecationWarning，**3.12+ 会变成 SyntaxError**。
   与本次发版无关，diff 保持聚焦所以没动，将来升级解释器前必须清一遍。
5. **外部备份会把 `.lanshare-pgpass` 拷到备份盘**：FAT/exFAT 上 ACL 无意义，
   口令会跟着 U 盘走。建议加 `/XF` 排除（与 rebocopy 参数一起改）。
