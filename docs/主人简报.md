## 11-17 → 11-19 干了什么

### 1. 十轮审查：两条真实越权 + 一个整库外泄口（4.0.16）

- **路径尾随点**：`private./...` 被 Win32 静默归一后落进「shared 全员可读」，
  普通成员能读别人的私人空间；`App安装包.` 还能绕过管理员写限制投递 APK。
- **`/local/*` 的 Host 可伪造**：配合隧道两步就能把整库 pg_dump 到外部共享盘。
  修法是在 Caddy 层直接 404（托盘和 CLI 直连本机端口，不受影响）。
- 另有：登出不吊销 App 凭据、关两步验证可无限猜密码、9 处写事务不回滚、
  7 处同步重活会冻住事件循环。

### 2. Cloudflare Tunnel：上线，然后你让它下线

- 4.0.17 做好了完整栏目（四步检测、同源校验、隧道启停）。
- 你 11-18 实测后拍板：首字节 3.39s vs FRP 0.064s，下载 0.52 vs 1.35 MB/s，
  差距 25~53 倍。于是托盘入口隐藏，C# 探测/启停逻辑保留不删。
- 方向改为「控制走 FRP，下载另开隧道」。设计稿待你拍板，尚未写代码。

### 3. 分片传输（App 4.1.9）

- ≥10MB 自动 8 路并发：CF 下 0.52 → 5.83 MB/s（11 倍），
  FRP 无收益（受总带宽限制）。
- 6 轮审查修 9 项，两条 P0：分片下载不响应取消、206 校验太晚可能写出坏文件。

### 4. 发版链

- 更新源改 R2 + 清单 Ed25519 签名；更新历史云端优先。
- 修了发版脚本三坑：更新历史解析不到新版本、build 号是假的、流程提速。
