# PC 端照片备份指南（不装 App，三种姿势）

家里 Windows 电脑上的照片也要进家庭网盘？不需要写客户端——LAN Share
服务端已经内置了 WebDAV（`/dav/`，独立密码，上限 20GB），PC 端按需挑一种：

| 姿势 | 适合人群 | 成本 |
|---|---|---|
| ① 脚本自动备份 | 想"插上就不用管" | 一次配置，10 分钟 |
| ② WebDAV 挂载成磁盘 | 喜欢拖拽复制 | 一次映射，5 分钟 |
| ③ 网页直传 | 偶尔传一批 | 零配置 |

## 0. 前置（所有姿势共通）

1. 在网页版右上角 **账号设置 → WebDAV 独立密码** 设置独立密码。
   （独立密码和登录密码互相独立，脚本/挂载工具只认这一个，泄露可单独轮换。）
2. 确认服务地址可访问：浏览器打开 `https://192.168.1.100:8765`。

## ① 脚本自动备份（推荐给"全家人共用那台电脑"的场景）

仓库自带 `scripts/pc-sync.py`（零第三方依赖，Windows 自带 Python 3 即可跑）：

1. 改脚本顶部 CONFIG 四行：服务器地址、账号、本机照片目录（密码走环境变量
   `LANSHARE_DAV_PASS` 更安全）。
2. 先空跑看清单：
   ```bat
   python scripts\pc-sync.py --dry-run
   ```
3. 正式同步：
   ```bat
   python scripts\pc-sync.py
   ```

行为说明：

- 落位 `照片/PC备份/<本机名>/`，与本机目录结构一致，照片墙会按 EXIF 拍摄日期
  自动入时间线（app 备份引擎同样可见）。
- **增量**：同路径+同大小+同 mtime 的文件自动跳过，反复跑、中断重跑都安全。
- 挂到任务计划每天自动跑：
  ```bat
  schtasks /Create /TN "lan-share-pc-sync" /SC DAILY /ST 12:00
    /TR "python C:\lan-share\scripts\pc-sync.py"
  ```

## ② WebDAV 挂载成"网络磁盘"（Windows 资源管理器）

1. 资源管理器 → 此电脑 → **映射网络驱动器**。
2. 文件夹填 `https://192.168.1.100:8765/dav/`，勾选"使用其他凭据"。
3. 弹窗里输 LAN Share 用户名 + **WebDAV 独立密码**。
4. 自签证书弹警告属正常（内网家庭服务），选择信任即可。

之后往映射盘里拖文件 = 直接入网盘。想备份照片库，把
`照片/PC备份/<本机名>/` 当作拖拽目的地即可。

> 注意：Windows 自带的 WebDAV 客户端对单文件有 ~50MB 的历史限制（注册表
> 可调）。**大视频建议用 ① 脚本或 ③ 网页直传**，别硬拖。

## ③ 网页直传

打开 `https://192.168.1.100:8765`，把整个文件夹拖进浏览器（支持目录上传、
分块续传，大文件走分片管线）。

## 常见问题

- **PROPFIND 401 / 405**：用了登录密码而不是 WebDAV 独立密码，或服务端
  Caddy 对 `/dav/` 的转发被拦——对照 `docs/OPERATIONS.md` §网络。
- **证书警告**：全家自签 TOFU 体系内属预期；手机 App 首次连接确认过同源
  指纹的话，PC 浏览器/脚本同样信任。
- **公网环境跑脚本**：注意樱花FRP 免费档 5GiB/月流量，大批量首传务必在
  局域网内完成。
